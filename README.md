# 🥗 Dr. Humberto Nicastro — Official Website

Landing page executiva, minimalista e de alta conversão para o **Dr. Humberto Nicastro** (Nutrição Esportiva, Fisiologia & Precisão Metabólica).

## 🚀 Tecnologias

- **HTML5 Semântico**
- **Tailwind CSS** (via CDN com personalização de paleta institucional)
- **Lucide Icons**
- **Mobile-First & Responsivo** (otimizado tanto para Link da Bio no Instagram quanto para Desktop)

## 📦 Estrutura do Projeto

```
dr-nicastro-site/
├── index.html        # Página principal com arquitetura clean e seções completas
├── assets/           # Imagens recortadas, otimizadas e logos oficiais
└── README.md
```

## ⚡ Deploy na Vercel

1. Acesse o painel da [Vercel](https://vercel.com).
2. Clique em **Add New...** > **Project**.
3. Importe o repositório `Jontecx/dr-nicastro-site`.
4. Mantenha as configurações padrão (Framework Preset: **Other**) e clique em **Deploy**.
5. O site estará online imediatamente com certificado SSL gratuito e alta velocidade de entrega (Edge Network).
